# Spark ERP Frontend

واجهة عربية RTL متكاملة لنظام Spark ERP مبنية بـ Next.js وTypeScript وTailwind CSS، ومتّصلة بواجهة NestJS عبر Cookies آمنة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`. يجب تشغيل الباك إند على المنفذ `4000` أولاً.

## الصفحات

- `/login` تسجيل الدخول
- `/dashboard` لوحة التحكم
- `/employees` إدارة الموظفين وإضافة موظف
- `/projects` مساحة المشاريع بستة أعمدة: المشاريع، الفريق، المهام، التفاصيل، بنود التنفيذ والتسليمات
- `/reports` تقارير الأداء
- `/settings` إعدادات النظام
- `/companies/spark` و`/companies/pro` صفحات الشركات

تسجيل الدخول وإدارة الموظفين والمشاريع والفرق والمهام وبنود التنفيذ والتسليمات متصلة بواجهة الـ API وقاعدة MongoDB. بيانات الإحصاءات والتقارير في لوحة التحكم وصفحة التقارير توضيحية إلى حين إضافة وحدات التقارير التشغيلية.
